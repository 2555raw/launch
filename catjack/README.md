# CATJACK 招财猫二十一点

一只猫荷官陪你打黑杰克，隔壁就是可以做多做空的「猫市场」。
纯前端演示：HTML + CSS + 原生 JavaScript，无构建步骤、无依赖、无后端。
直接用浏览器打开 `index.html` 即可运行。

## 玩法

**牌桌**
- 六副牌牌靴，余量低于 25% 自动重洗
- 发牌 / 要牌 / 停牌 / 加倍 / 新一局
- A 自动按 11 或 1 计算（显示为「软 17」这样的软牌点数）
- 天生黑杰克按 3:2 赔付，庄家按 17 点停牌规则自动行牌
- 快捷键：`H` 要牌 · `S` 停牌 · `D` 加倍 · `空格/回车` 发牌

**猫市场**
- 六只虚构标的（CATX / MEOW / PURR / WHSK / NINE / TUNA），每 2.6 秒按随机游走刷新
- 每只标的显示现价、涨跌幅、迷你走势图，并带偶发跳空行情
- **做多**：按现价买入，盈亏 = 数量 ×（现价 − 均价）
- **做空**：冻结等额保证金，盈亏 = 数量 ×（均价 − 现价）；
  价格涨到开仓均价的两倍即触发**强制平仓**，最大亏损为保证金
- 同一标的需先平仓才能反向开仓；单边手续费 0.2%
- 「最大」按钮：有持仓时等于全部平仓，无持仓时等于最大可开仓数量

**打通的地方**
- 牌桌赢来或输掉的筹码，直接变成市场上的可用资金，反之亦然
- 顶栏始终显示：筹码 | 持仓市值 | 总资产
- 猫会对发牌、爆牌、开仓、爆仓和行情剧烈波动做出不同表情和吐槽

## 设计说明

- 深色高级质感，黑蓝底 + 金色点缀 + 赌桌绿绒
- 配色遵循中国市场惯例：**红涨绿跌，红为盈、绿为亏**，牌局输赢也沿用同一套语义
- 招财猫元素：红项圈金铃铛、荷官帽上的「福」、牌背的「福」字、页面背景的「招財」印
- 完整响应式，移动端无横向溢出；尊重 `prefers-reduced-motion`

## 状态保存

筹码、持仓、行情、牌局与交易记录都存在 `localStorage`（键名 `catjack.v2`），刷新不丢。
页面底部「重置本局」可清空全部数据。筹码见底且无持仓时，可申请一次猫咪救济金（+250，不计入盈利）。
