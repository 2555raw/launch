Photography for the register

one line per reserve

Every plate on this site is cut from Hydropad's own photography. They are not photographs of these places, and none can be fetched from the machine that builds the site: every image host it would need is blocked there. Your browser has no such problem. Paste a ticker and a link on each line and the register uses them from here on.

Kept in this browser only.

Use images you have the right to use, and credit them. To make them part of the build instead of this browser, drop the files in media/sources/ as TICKER.jpg and run npm run photos, or paste what the copy button gives you over photos.js.

Hydropad is one open contract. No custody, no admin key, no owner: the only privileged call in it is withdrawing your own vault. Pairing a coin to a reserve names that body of water and nothing more, and conveys no ownership of it.
