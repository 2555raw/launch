VERIFY A RACE

Before a single wallet joins, the server publishes sha256(secret). It cannot change the secret after that without the hash changing. When the field closes it publishes the secret itself, and the race seed is sha256(secret + "|" + the list of players) - so the seed depends on a secret fixed before anyone joined and on a field nobody can edit afterwards.

This page re-runs the whole thing in your browser with the same engine the server used, and tells you whether the winner it announced is the winner the seed produces.
