## 3. Candidato #2 — CLAWNCH (launchpad "solo agentes" en Base)

### Takeaway
CLAWNCH es un launchpad donde solo agentes de IA del ecosistema OpenClaw/Moltbook pueden lanzar tokens. Los tokens se despliegan vía Clanker, con pool Uniswap v4 desde el bloque 1, y el agente se queda el 80% de las fees. El token CLAWNCH hizo ATH de US$41,5M (1-feb-2026) y después cotizó en US$7–12M. Es el arquetipo más relevante para quien construye launch sites. Además, su integración con MetaMask Delegation (límites de gasto onchain y kill switch) conecta directamente con las "spend policies" de Payence/Nomia.

**Producto y funcionamiento**
- Es un sistema de lanzamiento y reparto de fees "agent-only": no admite lanzamientos manuales. El flujo es:
  1. El agente publica un comando `!clawnch` con los metadatos del token en una red social de agentes (Moltbook, Moltx, 4claw), o usa la API, el servidor MCP o la CLI de Clawnch.
  2. Servicios off-chain escanean, validan y parsean el post; los scanners lo detectan en menos de un minuto.
  3. El token se despliega en Base con un pool Uniswap v4 completo desde el bloque 1, sin bonding curve.

  — [XT (Medium, mar-2026)](https://medium.com/@XT_com/clawnch-explained-how-agent-only-token-launches-work-on-base-92109c7a1df4); [XT blog](https://www.xt.com/en/blog/post/clawnch-explained-how-agent-only-token-launches-work-on-base); [docs de Clawnch](https://clawn.ch/docs).
- Reparto de fees 80/20 (agente/plataforma) con distribución automática. Los lanzamientos son exclusivos para agentes de Moltbook y se despliegan vía Clanker — [XT](https://www.xt.com/en/blog/post/clawnch-explained-how-agent-only-token-launches-work-on-base).
- Solo agentes "verificados" pueden lanzar; los humanos pueden tradear pero no lanzar. Lanzar es gratis, cada token recibe un pool Uniswap v4 con protección MEV integrada y los agentes se quedan el 80% de las fees — [MetaMask](https://metamask.io/news/clawnch-ai-agent-launchpad-delegation).
- Usa el protocolo social Moltbook para la comunicación entre agentes y Clanker para el despliegue sin intervención humana — [KuCoin](https://www.kucoin.com/news/articles/clawnch-market-cap-rebounds-to-7m-the-rise-of-the-next-gen-ai-agent-builder-on-base).
- Límites de gasto de los agentes (MetaMask Delegation Framework, vía Smart Accounts Kit) — [MetaMask](https://metamask.io/news/clawnch-ai-agent-launchpad-delegation):
  - un humano fija los límites una vez y un contrato los hace cumplir;
  - si una acción sale de esos límites, la transacción revierte;
  - `/delegate revoke` envía `disableDelegation` onchain y `/delegate revoke-all` corta todas las delegaciones a la vez;
  - antes de cada redención, Clawnch consulta el mapping de delegaciones deshabilitadas del DelegationManager, así que una revocación hecha fuera de Clawnch también surte efecto.

### Inferences
- **Payence** (tarjetas virtuales, spend policies, merchant locks):
  - El mercado ya valora "límites aplicados por contrato + kill switch" (Clawnch + MetaMask). La landing debería mostrar una demo en vivo de un agente con presupuesto limitado y revocable.
  - Para diferenciarse de MetaMask Agent Wallet, conviene destacar lo que un wallet no ofrece: tarjetas virtuales, merchant locks y rails off-chain.
  - Los launchpads de agentes como Clawnch son un canal B2B natural ("spend policies as a service").
- **Nomia** (rail de pagos para agentes, identidad por agente, liquidación multi-rail):
  - Alinearse explícitamente con x402.
  - Ofrecer un servidor MCP y publicar un skill en repos como base/skills.
  - Usar una mecánica tipo PING ("claim/mint pagando por el rail de Nomia") como demo de lanzamiento, pero con un token que capture fees del volumen liquidado.
- **Tricker** (bags de 3–5 activos):
  - Las narrativas de Base (agentes, x402, launchpads) se mueven en bloque y rotan rápido. Una bag temática, p. ej. "economía de agentes de Base" (VIRTUAL, CLANKER, CLAWNCH), permite exponerse a la narrativa sin elegir un ganador.
  - Esto es una inferencia: no se verificaron productos de índice comparables en Base.
- **Tricker Terminal**:
  - Copiar de AIN el cobro por consulta vía x402, con agentes como clientes, y listarse en exploradores x402.
- **Diseño de token para el próximo lanzamiento**:
  - Lanzar sobre un launcher con un fee loop visible:
    - Flaunch, si se quieren buybacks o bid wall programables;
    - Bankr o Zora sobre Doppler, para la máxima distribución en Base;
    - Clanker, para distribución en Farcaster.
  - Mostrar en la web el split de fees, el contrato, el launchpad y métricas en vivo (fees pagadas, volumen).
  - Evitar utilidades de "descuento" y KPIs de vanidad.
- **Diseño del launch site** (Next.js/Tailwind o HTML estático):
  - un bloque "contrato + launchpad + fee split" arriba;
  - una sección "para agentes" (API, MCP, CLI, skill.md);
  - badges de integración (x402, Base skills, MetaMask Delegation);
  - un panel de métricas onchain;
  - transparencia sobre el equipo (el pseudonimato es habitual, pero penaliza la confianza).
