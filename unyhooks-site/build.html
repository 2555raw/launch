SwapFeeHook.sol

Deploy on Robinhood Chain

  1. 1
    Connect your wallet

    MetaMask, Phantom or any browser wallet. You'll need a little ETH on Robinhood Chain for gas.

  2. 2
    Deploy the hook

    Compiles in your browser, finds an address with the right permission bits, then asks for one signature.

  3. 3
    Create the pool

    Pick the pair and a starting price. The pool goes live on Uniswap V4 with your hook.

    1 token =ETH

    This hook sets the fee itself, so the pool is created with Uniswap's dynamic-fee flag.

  4. 4
    Add liquidity

    Deposit both tokens so people can trade. You keep the position and earn the pool's fees.

Not audited, and this is mainnet with real money. Read the code, start with small amounts, and have the hook reviewed before it holds real funds.

Prefer to deploy with Foundry?
  1. Make a project: forge init my-hook && cd my-hook
  2. Add Uniswap V4: forge install uniswap/v4-periphery and the remappings @uniswap/v4-core/=lib/v4-periphery/lib/v4-core/, @uniswap/v4-periphery/=lib/v4-periphery/
  3. Save the hook as src/SwapFeeHook.sol and the deploy script as script/DeploySwapFeeHook.s.sol, with evm_version = "cancun" in foundry.toml
  4. Run the command at the top of the deploy script with POOL_MANAGER=
