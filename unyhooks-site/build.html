    Deploy it

    One-click deploys from the browser are next. Until then, a developer can deploy it in a few minutes with Foundry:

    1. Make a project: forge init my-hook && cd my-hook
    2. Add Uniswap V4: forge install uniswap/v4-periphery and the remapping @uniswap/v4-core/=lib/v4-periphery/lib/v4-core/, @uniswap/v4-periphery/=lib/v4-periphery/
    3. Save the hook as src/SwapFeeHook.sol and the deploy script as script/DeploySwapFeeHook.s.sol, with evm_version = "cancun" in foundry.toml
    4. Run the command at the top of the deploy script, with the PoolManager address for Robinhood Chain

    Not audited. Test on a fork or testnet and have the hook reviewed before it holds real money.
