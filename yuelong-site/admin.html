Deploy Yuelong.

Put the contracts on a chain from your own wallet and switch the site on. Your key never leaves the wallet; this page only asks it to sign.

Ownership

Connect the wallet that should own Yuelong. When the contracts were deployed for you, they wait here for that wallet to accept them: one signature, no admin key needed.

1 · Admin key

The ADMIN_KEY variable of the Railway service. It only lets this page save which contracts the site shows.

2 · Deploy from your wallet

    Or · import a deployment

    Paste contracts/out/deployment.<chainId>.json from npm run deploy. The server checks it against the chain before using it.
